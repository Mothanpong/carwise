CARWISE — เว็บต้นแบบ Heuristic Search สำหรับ Group 12

เปิดใช้งาน
ดับเบิลคลิก index.html เพื่อเปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งแพ็กเกจและไม่ต้องใช้อินเทอร์เน็ต
เก็บ index.html, styles.css, engine.js และ app.js ไว้ในโฟลเดอร์เดียวกัน
ข้อมูลที่เก็บแยกตามเบราว์เซอร์และที่อยู่เว็บ การเปิดผ่านไฟล์กับ localhost จะเป็นคนละพื้นที่จัดเก็บ

สิ่งที่ใช้งานได้
- คัดกรอง 4 กลุ่มอาการ พร้อมข้อมูลรถและบริบท
- Safety gate ก่อนเริ่มคำถาม และหยุดเมื่อไม่ทราบ 2 คำตอบ
- เลือกคำถามตาม h(n)=S×E/(R+1) และปรับคะแนนตามคำตอบ
- เก็บแบบร่าง ประวัติ และเคสใน localStorage
- สรุปอาการ แสดงหลักฐานและข้อสงสัยแยกกัน
- ดาวน์โหลด .txt, .json และพิมพ์/บันทึก PDF ผ่านเบราว์เซอร์
- ส่งเคสเข้าพื้นที่ช่างในเครื่องเดียวกัน รับเคส บันทึกผลตรวจและแผนดำเนินการ
- นำเข้าไฟล์เคส .json เพื่อย้ายข้อมูลระหว่างเครื่อง
- หน้าจอรองรับมือถือและคีย์บอร์ด

ขั้นตอนสาธิต
1. กดอาการหรือเริ่มคัดกรอง → กรอกข้อมูลรถ
2. ตอบ Safety gate → ตอบคำถามจากสิ่งที่เคยสังเกต
3. อ่าน Diagnostic Summary → ส่งเข้าพื้นที่ช่าง
4. เปิดพื้นที่ช่าง → รับเคส → กรอกผลตรวจ → บันทึก
5. กลับประวัติ → เปิดเคสเดิมเพื่อดูบันทึกของช่าง
มีปุ่ม “ดูเคสตัวอย่าง” สำหรับเพิ่มเคสสมมติที่ติดป้ายชัดเจน

ขอบเขต
เป็นต้นแบบทำงานจริงในเบราว์เซอร์ ใช้กฎและคะแนนจำลอง ไม่ใช่บริการวินิจฉัยรถที่ผ่านการรับรอง
ไม่มี AI/API ภายนอก ฐานข้อมูลส่วนกลาง บัญชีผู้ใช้ หรือการส่งเคสให้อู่จริง
การวินิจฉัยและการรับรองความปลอดภัยต้องมาจากช่างที่ตรวจรถจริง
ในต้นแบบ ทุกคนที่เข้าถึงเครื่องสามารถสลับไปพื้นที่ช่างได้ ไม่ถือว่าเป็นระบบยืนยันตัวตน
ก่อนใช้งานกับลูกค้าจริง ต้องพัฒนาระบบบัญชี การจัดเก็บข้อมูลและสิทธิ์เข้าถึง รวมถึงฐานความรู้ที่ผู้เชี่ยวชาญตรวจรับรอง
การล้างข้อมูลเบราว์เซอร์จะลบเคส ควรส่งออก .json เพื่อสำรอง

ไฟล์
index.html — จุดเข้าเว็บ
styles.css — หน้าตาและ responsive layout
engine.js — กฎ คำถาม คะแนน และการตรวจรูปแบบเคส
app.js — หน้าจอ การเก็บข้อมูล และการส่งออก/นำเข้า
